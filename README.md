# Wifi Bekçisi

Windows için küçük bir terminal aracı. İnternet koparsa seçtiğin Wi-Fi ağına otomatik yeniden bağlanır.

Python 3.8 veya üstü yeterli, ek paket gerekmez.

```
python bekci.py kur
python bekci.py baslat
python bekci.py otostart ac
```

Argümansız çalıştırırsan menü açılır. Diğer komutlar: durum, canli, durdur, ag, log.

Adaptör ve servis yenileme adımları için yönetici olarak çalıştır.
